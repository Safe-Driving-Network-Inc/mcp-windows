Welcome

Your Kareenos agents can now work in the programs on this computer while you are at your desk. Three steps:

  1. Installed. The Desktop Agent lives in the tray, next to the clock, and starts with Windows.
  2. Connect this computer to a project. In Kareenos open Browsers & Desktops, pick the project and click Connect this computer. When the browser asks, allow it to open the Kareenos Desktop Agent.
  3. If nothing happened, paste the connection code the page shows:

Agents pause while you use the mouse or keyboard. Pause agents in the tray menu stops them entirely. The agent never asks for, and never types, a password.
