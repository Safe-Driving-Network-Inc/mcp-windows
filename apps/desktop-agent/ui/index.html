Your agents, in your programs

Your Kareenos agents can work in the programs on this computer. Three steps:

  1. Installed. The Desktop Agent lives in the tray, next to the clock, and starts with Windows.
  2. Connect this computer. In Kareenos open Browsers & Desktops and click Connect this computer, or add it under Computers and copy its connection code. When the browser asks, allow it to open the Kareenos Desktop Agent.
  3. If nothing happened, paste the connection code the page shows:

Agents pause while you use the mouse or keyboard. Pause agents in the tray menu stops them entirely. The agent never asks for, and never types, a password.
